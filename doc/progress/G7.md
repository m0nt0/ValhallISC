## Delivered
- `mount/manager.py`: `MountManager`.
  - States INACTIVE → MOUNTING → ACTIVE → UNMOUNTING, published to subscribers.
  - A mount timeout (30 s) kills the worker.
  - Unmount escalation: `stop`, then a forced OS unmount, then kill.
  - BUSY returns the state to ACTIVE, so the GUI can offer to force.
  - A worker crash is detected, the user is notified, and the dead mount is removed.
  - `unmount_all(wait=…)` stops every worker in parallel (for Quit).
  - `cleanup_stale()` runs at startup.
  - Overlapping mount points are refused, and the store's `is_active` hook is wired up.
- `tests/fakes/fake_worker.py`: scripted worker scenarios (ok, auth_fail, hang, busy, crash, ignore_stop).
- E2E: two profiles mounted at once plus `unmount_all`; wrong password; SIGKILL of a worker; stale-mount cleanup on startup; busy then forced unmount.

## Findings fixed during the gate
1. **Mount detection hung or lied on dead mounts (macOS).** `os.path.ismount` stats the mount point. When the FUSE worker is dead, macFUSE blocks until its daemon timeout or fails, so dead mounts were never cleaned and runs took 3 minutes. Detection now reads the **mount table** (`mount` output), and the mount point itself is never stat-ed (`unmount.canonical` resolves only the parent). Mount point validation checks the table before any stat.
2. **"mounted" was reported too early (macOS).** FUSE's `init` callback runs before the mount is visible to other processes. Readers hit the empty folder underneath, and a startup cleanup could miss a mount that appeared a moment later. The worker now announces `mounted` only once the mount table shows it.
3. **False positive in the leftover check:** `pgrep -f "irisfs worker"` matched a shell whose command line contained that text. The pattern is now anchored to real worker command lines.
4. One macOS run had an extra failure next to a "Resource busy" unmount warning from a test fixture. It didn't recur in the next 3 consecutive runs. The fixture escalates to a forced unmount, and the leftover check stayed clean. **Watch item.**

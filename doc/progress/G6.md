## Bugs found and fixed during the gate
1. **Copying the same file in twice within 60 s failed with ENOENT.** `open(O_WRONLY)` on a ghost entry fell through to the server lookup. A ghost opened for writing now becomes a new write buffer. Regression tests were added.
2. **`ditto` (and Finder's copy engine) failed with "Permission denied".** They write a hidden temporary file (`.BC.T_xxxx`) and then rename it. Hidden temporary files are now in-memory scratch files, and renaming one to `*.xml` imports it (`EIO` if the XML is invalid). This also makes editors' atomic saves work. Visible non-XML names such as `notes.txt` are still refused. Regression tests were added.
3. Scratch handles now reference the scratch object instead of its path, so a file renamed while open keeps working.

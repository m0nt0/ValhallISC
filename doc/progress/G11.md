## Delivered
- `irisfs/clicommands.py`:
  - `profile list|show|create|update|delete`, `test`, `connect`, `disconnect`, `status`;
  - flag aliases (`--create-profile NAME`, `--connect NAME`, …);
  - `--batch`: JSON output and fixed exit codes (see `doc/CLI.md`).
- `irisfs/mount/registry.py`: the shared mount registry. Workers register once mounted and unregister on exit; entries with a dead pid are ignored.
- `irisfs/mount/detached.py`: background mounts that outlive the CLI (`start_new_session` on POSIX; `DETACHED_PROCESS` / `CREATE_NO_WINDOW` on Windows), and disconnect (unmount on POSIX; `taskkill /T` on Windows).
- The tray and CLI interoperate:
  - `MountManager` reports CLI mounts as ACTIVE, can unmount them, keeps them out of stale cleanup, and leaves them mounted on Quit;
  - the tray menu labels them "(connected from CLI)";
  - a worker exiting with code 0 isn't reported as a crash.
- `mountpoint.ensure_folder()` is shared by the GUI and the CLI. `VALHALLISC_SECRETS=file` keeps the tests away from the OS keyring.

## Deviations from the plan
- The export and import endpoints are `action/xml/export` and `action/xml/load` (Atelier v7+), not `doc?format=xml` or `cvt`.
- The "system item" filter uses the `db`, `dbsys` and `upd` fields (ADR-003), not just the `%` prefix.
- The macOS tray needs a hidden frame, and the icon needs PyObjC to set the template flag (ADR-005). The user asked for an InterSystems logo; the icon will be loaded from a user-supplied file, with the drawn glyph as fallback.
- The Linux test image uses Ubuntu's `python3-wxgtk4.0`, because the extras wheels are x86_64-only and the host is arm64.

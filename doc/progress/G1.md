## Notes
- `scripts/test.sh` treats pytest exit code 5 ("no tests collected") as OK, so empty suites don't fail early gates. From G3 on, every suite will contain tests.
- `docker-compose.yml` sets `init: true` on `linux-test`. Without an init process, `xvfb-run` runs as PID 1, never receives Xvfb's ready signal, and hangs.
- The Linux image uses Ubuntu's wxPython 4.2.1, while macOS uses the pip wheel 4.3.1. The GUI code must work with both.

## Findings
1. **A onefile binary is unusable on macOS:** 10–103 s startups, because it re-extracts and macOS re-scans on every launch. The macOS CLI is now a wrapper around the bundle executable (ADR-009).
2. **Case-insensitive name clashes:** `dist/ValhallISC` vs `dist/valhallisc` (APFS) deleted the CLI binary. On Windows, `ValhallISC.exe` vs `valhallisc.exe` would clash the same way. Renamed (`ValhallISC-onedir`, `valhallisc-cli.exe`).
3. The first macOS build took 53 minutes of mostly idle waiting (PyInstaller's binary cache). Rebuilds take about 2 minutes.
4. Linux build prerequisites: `binutils` (objdump) and `libpython3.12t64`, added to the image.
5. Windowed builds may have `sys.std* = None`. Logging and the worker's streams now handle that.
